# PCB Quality Gate · 缺陷智能质检台

> 面向 PCB 产线的**可解释质量判定层**原型。不把「用了 YOLO/AI」当创新——真正的改动在**误报过滤 + 致命度分级 + 板级可解释判定**，并用可复现基准给出三档对照实测。

版本：1.0.0　|　技术栈：Python 3.13 · NumPy · OpenCV · 标准库 HTTP 服务（零 Web 框架）　|　许可：MIT

---

## 1. 问题场景与价值

PCB 制造中，缺陷检测只是手段，**产线真正要的决策是「这块板能不能放行」**。一线常见两个痛点：

- **漏检**：漏孔、鼠咬、开路这类「结构缺失」缺陷，在简单颜色阈值下完全看不见；
- **过杀**：哪怕只是一个 0.2mm 的毛刺也判 NG，导致大量本可放行的板被误废，浪费成本。

受影响对象：SMT 产线质检员、AOI 设备集成商。可测量价值：**用同一批样本，把板级误判从 71.4% 降到 1.4%**（见第 4 节）。

## 2. 方案与核心创新点

系统分三层，前端检测器可替换，创新集中在判定层：

```
观测板 ─→ [前端检测] ─→ 候选缺陷框 ─→ [判定层] ─→ OK/NG + 严重度 + 逐条理由
              │                          │
        基线: 单色阈值              ① 误报过滤（面积/贴边）
        改进: 标准板参考差分        ② 致命度分级（IPC 简化规则）
        (可替换为 YOLO bbox)         ③ 板级判定 + 可解释输出
```

**最小创新点（一条主线）**：在检测结果之上增加一层**可解释的致命度判定**——把「检出缺陷」变成「按工艺严重度决定放行的决策」，并明确区分「检出层」和「判定层」的贡献，使两者可独立评测。

**具体技术改动（相对基线）**：

| 环节 | 基线做法 | 本作品改动 | 为什么有效 |
|---|---|---|---|
| 缺陷发现 | 单色阈值分割，只看「颜色突变」 | 标准板参考差分（golden board comparison） | 结构缺失型缺陷（孔/缺口/断线）在差分下可见 |
| 缺陷分类 | 不分类，统一 unknown | 连通域形状先验 → 6 类缺陷 + 严重度 | 为分级判定提供依据 |
| 板级决策 | 有框即 NG | 误报过滤 + 致命度分级 + 可解释理由 | minor 缺陷放行，减少过杀；输出可追溯 |

> 说明：改进层的前端目前用参考差分实现，**接口 `Detection` 与 YOLO bbox 对齐**，替换检测模型不需要改判定层。本作品刻意不依赖深度学习权重，保证零依赖、可现场复现——这本身就是工程完整性的一部分。

## 3. 数据与方法

**数据集**：程序化合成，对齐北京大学 PKU-Market-PCB 的 6 类缺陷（漏孔 missing_hole、鼠咬 mouse_bite、开路 open_circuit、短路 short、毛刺 spur、杂铜 spurious_copper）。合成器 `pcbqg/synth.py` 用 `seed` 控制，完全可复现。

> 为什么用合成数据：真实 PKU 数据集需向作者申请；且其原始缺陷本身是用 Photoshop 合成标注的。本作品用参数化合成提供**等价的可复现实验条件**，并显式声明这一限制（见第 5 节）。

**实验设置**（`experiments/results.json`）：140 块板 = 6 类 × 20 + 20 块良板；IoU 命中阈值 0.15，三档完全一致以保证对照公平。

**指标**：缺陷级召回率/精确率/F1、分类型召回；板级判定准确率、漏检板(FN board)、误报板(FP board)；严重度判定准确率。

## 4. 结果（实测，非估算）

| 档位 | 缺陷召回 | 板级准确率 | 漏检板 | 误报板 | 严重度准确率 | F1 |
|---|---|---|---|---|---|---|
| 基线 · 单色阈值 | 50.0% | 28.6% | 60 | 40 | — | 0.67 |
| 改进 · 参考差分 | 100% | 71.4% | 0 | 40 | 98.3% | 1.00 |
| **改进 + 判定层** | **100%** | **98.6%** | **0** | **2** | **98.3%** | **1.00** |

**读法**：

- 基线对 3 类「缺口型」缺陷（漏孔/鼠咬/开路）召回为 0 —— 这是它的结构性盲区，见 `fig3_per_class.png`；
- 改进层把召回拉到 100%，但因为**不分级**，40 块 minor 缺陷板全部过杀，板级准确率仅 71.4%；
- 判定层过滤误报并按严重度放行 minor 缺陷，把板级误判从 100 块压到 2 块。

**难度鲁棒性（适用边界证据）**：

| 难度 | 基线板级 | 判定层板级 | 判定层召回 |
|---|---|---|---|
| 简单 | 28.6% | 100% | 100% |
| 正常 | 28.6% | 98.6% | 100% |
| 困难（缺陷缩小至 0.65×） | 28.6% | 80.9% | 90.0% |

## 5. 失败边界与限制（诚实声明）

1. **合成数据 ≠ 真实产线**：真实 PCB 有纹理、丝印、反光、密集走线，本基准无法覆盖；迁移到真实场景需重新采集标准板并标定。
2. **极小缺陷**：hard 档（缺陷缩至 0.65×）板级准确率降到 80.9%，召回 90%——小于约 5px 的目标在 640×640 下不可靠。
3. **依赖标准板**：参考差分法要求一张对齐的理想板；产线需首件检验或 CAD 渲染图生成，存在配准误差来源。
4. **形状分类是启发式**：严重度判定准确率 98.3%，仍有约 1.7% 分错，边界样本（介于 spur 与 mouse_bite 之间）会误分级。

## 6. 现场演示

```bash
# 方式一：Windows 双击（推荐，自动开浏览器）
run_demo.bat

# 方式二：命令行
python server.py            # 打开 http://127.0.0.1:8765
```

界面功能：选缺陷类型/种子/难度 → 生成样本并检测 → 五视图对照（原图/真值/基线/改进/判定层）→ 判定理由 → 一键运行三档对照实验。全程本地计算。

```bash
# 命令行跑实验
python -c "from pcbqg import run_experiment; import json; print(json.dumps(run_experiment(),ensure_ascii=False,indent=2))"

# 单元测试
python -m unittest discover -s tests -v     # 10 tests, all passed
```
